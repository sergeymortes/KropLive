## 📱 Про застосунок

**Кроп Live** - Android-застосунок для жителів Кропивницького, який допомагає залишатися в курсі важливих подій та змін у місті.

Графіки відключень електроенергії, повітряні тривоги, водопостачання, погода та міські сервіси - усе в одному зручному інтерфейсі.

Застосунок орієнтований на персоналізовану інформацію відповідно до адреси користувача.

## ✨ Основні можливості

### ⚡ Електроенергія

- 🔌 Планові відключення електропостачання.
- 🚨 Інформація про аварійні відключення.
- 📅 Перевірка погодинних графіків відключень (ГПВ).
- 🏠 Дані відповідно до збереженої адреси та черги.
- 🌐 Отримання інформації з офіційних джерел.
- 📢 Додаткова перевірка графіків через Telegram.
- ⏰ Нагадування про заплановані відключення.

### 🚨 НЕПТУН - повітряні тривоги

Інтегрована система моніторингу повітряних тривог.

- 🗺️ Інтерактивна карта НЕПТУН.
- 📍 Відображення стану для відповідного району.
- 🔔 Сповіщення про зміни стану тривоги.
- 🔄 Оновлення інформації та використання кешованих даних.
- 📡 Фоновий моніторинг з урахуванням обмежень Android.

### 💧 Водопостачання

- Інформаційні повідомлення щодо водопостачання.
- Перегляд доступних даних для вибраної адреси.
- Зручний доступ із головного екрана.

### 🌿 Екостайл

- Інтеграція інформації сервісу «Екостайл».
- Робота з адресними даними.
- Використання географічних координат для відповідних функцій.

### 🌤️ Погода

- Окремий розділ із погодною інформацією.
- Швидкий перехід із головного екрана.

### 🏠 Персональні налаштування

- Збереження адреси користувача.
- Вибір вулиці, будинку та черги електропостачання.
- Можливість змінити адресу.
- Світла та темна теми.
- Україномовний інтерфейс.

## 🔄 Автоматичні оновлення

Кроп Live підтримує перевірку нових версій через **GitHub Releases**.

Коли доступна нова версія, застосунок може:

1. Повідомити користувача про оновлення.
2. Показати номер нової версії та опис змін.
3. Завантажити APK із відображенням прогресу.
4. Передати файл системному інсталятору Android.

Встановлення відбувається лише після підтвердження користувача.

## 📥 Завантаження та встановлення

### [⬇️ Завантажити останню версію Кроп Live](https://github.com/sergeymortes/KropLive/releases/latest)

**Інструкція:**

1. Перейдіть до розділу [Releases](https://github.com/sergeymortes/KropLive/releases).
2. Відкрийте останній стабільний реліз.
3. У розділі **Assets** завантажте файл `.apk`.
4. Відкрийте APK на Android-пристрої.
5. За потреби надайте дозвіл на встановлення застосунків із цього джерела.
6. Підтвердьте встановлення.

**Системні вимоги:** Android 8.0 (API 26) або новіший, підключення до інтернету для отримання актуальних даних.

## 🧑‍💻 Збірка з вихідного коду

1. Клонуйте репозиторій:

   ```bash
   git clone https://github.com/sergeymortes/KropLive.git
   ```

2. Відкрийте проєкт в Android Studio.
3. Дочекайтеся синхронізації Gradle.
4. Підключіть Android-пристрій або запустіть емулятор.
5. Натисніть **Run**.

Для створення підписаного Release APK потрібен власний ключ підпису.

**Application ID:** `ua.kropilive.app`

## 🔐 Дозволи

Застосунок може використовувати:

- **Інтернет** - для завантаження актуальної інформації.
- **Сповіщення** - для важливих повідомлень.
- **Точні нагадування** - для запланованих попереджень.
- **Фонову роботу** - для підтримуваних сценаріїв моніторингу.
- **Встановлення APK** - для оновлень через GitHub за згодою користувача.

Доступність окремих функцій залежить від версії Android, налаштувань пристрою та наданих дозволів.
